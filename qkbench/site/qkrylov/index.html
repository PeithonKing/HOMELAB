qkrylov

Exact diagonalization of quantum many-body systems, without storing the matrix. One engine for Python, Julia, C++ and C, on CPUs and GPUs.
InstallQuickstartGitHub

qkrylov finds the lowest energy levels of spin and fermion models, and computes thermal averages, spectral functions and real-time dynamics, for systems far too large to write down as a matrix. A 32-site spin chain has 600 million states; qkrylov solves it on one GPU in under 20 seconds.

Matrix-free

The Hamiltonian is never stored, so memory is a few vectors. For a 28-site chain that is about 3 GB, where a stored matrix needs 7.5 GB more.

Fast on any hardware

All CPU cores through OpenMP and NVIDIA GPUs through CUDA, from the same code. 16 to 40 times faster than a stored-matrix library on the same machine, without symmetries.

Four languages

Python, Julia, C++ and C call the same engine. Results are identical, run times within a few percent.

Checked against exact answers

Every tutorial program runs in all four languages and is checked against a dense solver or a known value.
