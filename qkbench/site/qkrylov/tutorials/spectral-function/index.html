Tutorial: spectral functions

Energies tell you what levels a system has. A spectral function tells you which of them you can reach by poking the system, and how strongly. Take the ground state |0⟩ and a probe, here the spin component Sz on site 0. The spectral function is a series of peaks, one per excited level |n⟩ at the excitation energy ωn = En − E0, each with weight |⟨n|Sz0|0⟩|2:

S(ω)=∑n∣⟨n∣S0z∣0⟩∣2  δ(ω−(En−E0)).S(\omega) = \sum_n \big| \langle n | S^z_0 | 0 \rangle \big|^2 \; \delta\big(\omega - (E_n - E_0)\big).S(ω)=n∑​​⟨n∣S0z​∣0⟩​2δ(ω−(En​−E0​)).

Experiments such as neutron scattering measure quantities of this kind.

Without finding the levels

Section titled “Without finding the levels”

Computing S(ω) from the definition needs every level |n⟩, which is out of reach for large systems. The continued-fraction method gets the same curve from one Lanczos run: start from the disturbed state |φ⟩ = Sz0|0⟩ and run Lanczos on H from there. The recursion produces the coefficients of a continued fraction whose imaginary part is S(ω), with each delta peak widened to a bell shape of width η so it can be drawn and evaluated at any ω:

S(ω)=−1π Im ⟨ϕ∣ 1ω+E0−H+iη ∣ϕ⟩.S(\omega) = -\frac{1}{\pi}\, \mathrm{Im}\, \Big\langle \phi \Big|\, \frac{1}{\omega + E_0 - H + i\eta}\, \Big| \phi \Big\rangle .S(ω)=−π1​Im⟨ϕ​ω+E0​−H+iη1​​ϕ⟩.

The program

Section titled “The program”

Four steps: find the ground state, apply the operator to it, run the continued fraction, and evaluate S(ω). The operator Sz0 is built like a Hamiltonian, with a single term, and applied with the same operations you use for products with H.

The norm of the disturbed state is 0.5: the square of it, 1/4, is the total weight of all the peaks (Sz on a spin-1/2 squares to 1/4), a sum rule that you can use to check any spectral calculation.

Check against the exact spectrum

Section titled “Check against the exact spectrum”

For this 12-site ring (924 states) you can also compute the levels and weights exactly, and sum one bell-shaped peak per level. This is again a check of the method, not something to do for large systems:

The two curves differ by about 3e-8 at most: with 100 Lanczos steps the continued fraction reproduces the exact curve, even though it never computed a single level. The integral over a finite window is 2% short of the sum rule only because the tails of the bell shapes extend beyond it.

Reading the result

Section titled “Reading the result”
  • The spectrum starts at the spin gap. The lowest level with any weight is at ω = 0.3559, exactly the spin gap of this ring from the excited-states tutorial (0.355848 for 12 sites). It carries about a quarter of the total weight; the rest is spread over higher levels, 155 of the 924 levels in all.
  • η is a choice. A smaller η resolves finer detail but needs more Lanczos steps to stay smooth; a larger η smooths the curve. The method gives the exact answer for any η as long as it has enough steps.

Other operators

Section titled “Other operators”

To probe a different operator, build a one-term operator sum for it, apply it to the ground state and run the continued fraction. A correction-vector solver gets S(ω) at one chosen frequency by solving a linear system instead of building a continued fraction; see the API reference.
