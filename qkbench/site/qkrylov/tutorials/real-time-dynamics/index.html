Tutorial: real-time dynamics

The earlier tutorials looked at energy levels. Real-time dynamics asks a different question: prepare the system in some state and let it evolve. Quantum mechanics says the state at time t is

∣ψ(t)⟩=e−iHt ∣ψ(0)⟩,|\psi(t)\rangle = e^{-iHt}\, |\psi(0)\rangle,∣ψ(t)⟩=e−iHt∣ψ(0)⟩,

the Hamiltonian’s matrix exponential applied to the starting vector. Qkrylov never forms that exponential. It builds the small Krylov subspace of H around the starting vector, exponentiates the tiny Lanczos matrix, and maps the result back, which gives the evolved state at every requested time.

A quench from a Néel state

Section titled “A quench from a Néel state”

The starting state is the Néel state: spins alternating up and down around the ring, which is a single basis state. It is not an eigenstate of the Heisenberg Hamiltonian, so it evolves, and the spins slowly lose the alternating order. The program follows the spin Sz on site 0, which starts at +1/2, and the return probability, the chance of finding the system back in the Néel state.

Things to know

Section titled “Things to know”
  • The result is a list over times. You give a grid of times and get the observables and the return amplitude at each. Longer times need more Krylov steps (n_steps); check by repeating with a larger value.
  • Observables are one-term Hamiltonians. Any quantity you can write as an operator sum can be followed this way; pass several at once to measure them all from the same evolution.
  • The return amplitude. The solver reports the complex overlap ⟨ψ(0)|ψ(t)⟩ (the field is called survival_probabilities); the probability is its squared magnitude, as the programs print.
